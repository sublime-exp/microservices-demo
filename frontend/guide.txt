1. Create a tailwind.config.js manually.
Create a file named tailwind.config.js in your root project folder:
module.exports = {
  content: [
    "./src/**/*.{html,ts}"
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}

The above configuration will apply tailwind CSS to all the HTML templates in our project.
To enable CSS, we also have to update the src/styles.css file with the following code:

@tailwind base;
@tailwind components;
@tailwind utilities;
